## Installation

<Steps>

### Install core dependencies

Glass UI components rely on a few standard utilities to merge Tailwind classes and render icons. Install them in your project:

<CommandTabs
  npm="npm install clsx tailwind-merge lucide-react"
  pnpm="pnpm add clsx tailwind-merge lucide-react"
  yarn="yarn add clsx tailwind-merge lucide-react"
  bun="bun add clsx tailwind-merge lucide-react"
  client:load
/>

### Install Tailwind CSS

Glass UI requires Tailwind CSS v4 for its styling and CSS-first theming. If you haven't set it up yet, please follow the <ExternalLink href="https://tailwindcss.com/docs/installation" className="underline">official Tailwind CSS installation guide</ExternalLink> for your specific framework.

### Configure Path Aliases

Ensure your project has path aliases configured. Update your `tsconfig.json` (or `tsconfig.app.json` if using Vite) to include the `@/*` alias:

<CodeBlock
  client:load
  filename="tsconfig.json"
  showLineNumbers
  highlightLines="3-5"
  lang="json"
  code={`{
    "compilerOptions": {
      "paths": {
        "@/*": ["./src/*"]
      },
    },
  }`}
/>

If your project already uses a different prefix (like ~/\*), you can use that instead, but remember to update the imports in the components you copy later.

### Add the utility function

Create a `src/lib/utils.ts` file. This helper function is used by all Glass UI components to conditionally merge Tailwind classes without style conflicts:

<CodeBlock
  client:load 
  lang="ts"
  filename="src/lib/utils.ts"
  showLineNumbers
  code={`import { clsx, type ClassValue } from "clsx"
  import { twMerge } from "tailwind-merge"

  export function cn(...inputs: ClassValue[]) {
    return twMerge(clsx(inputs))
  }`}
/>

### Add the configuration file

Create a `glass.config.json` file at the root of your project:

<CodeBlock
  client:load
  lang="json"
  filename="glass.config.json"
  showLineNumbers
  code={`{
    "framework": "remix",
    "style": "default",
    "css": "app/app.css",
    "aliases": {
      "components": "@/components/ui",
      "utils": "@/lib/utils"
    }
  }`}
/>

Adjust the `framework` and `css` paths according to your project structure. The `aliases` defined here must match your `tsconfig.json` exactly.
