## Requirements

Ensure your existing project meets these requirements before selecting your framework.

<ul className="list-disc pl-5">

  <li>Styled with <strong>Tailwind CSS v4</strong>.</li>

## Icons

Many of our components and examples are designed to work harmoniously with <ExternalLink href="https://lucide.dev">Lucide React</ExternalLink>, a beautiful, consistent, and lightweight icon toolkit.

We highly recommend installing it before you begin:

<CommandTabs 
  npm="npm install lucide-react" 
  pnpm="pnpm add lucide-react"
  yarn="yarn add lucide-react"
  bun="bun add lucide-react"
  client:load 
/>
