## Styling

Input now follows the same prop-first API direction as Button. Reach for `variant` and `size` first, then use `className` as an escape hatch for one-off layout or state styling.

<CodeBlock 
  lang="tsx"
  code={`/* Variants */
  <Input variant="default" />
  <Input variant="soft" />
  <Input variant="strong" />
  <Input variant="transparent" />

  /* Sizes (defaults to md) */

  <Input size="sm" />
  <Input size="md" />
  <Input size="lg" />

  /* Native invalid state */

  <Input aria-invalid="true" />`}
/>

## API Reference

| Prop        | Type                                               |
| ----------- | -------------------------------------------------- |
| `variant`   | `"default" \| "soft" \| "strong" \| "transparent"` |
| `size`      | `"sm" \| "md" \| "lg"`                             |
| `className` | `string`                                           |
