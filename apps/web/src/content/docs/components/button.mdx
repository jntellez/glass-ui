## Installation

Run the following command to add the `Button` component to your project:

<CommandTabs
  npm="npx glass-ui add button"
  pnpm="pnpm dlx glass-ui add button"
  yarn="yarn dlx glass-ui add button"
  bun="bunx glass-ui add button"
  client:load
/>

## Usage

Import the component and use it in your React application:

<CodeBlock 
  lang="tsx"
  code={`import { Button } from "@/components/ui/button"

  export default function ButtonDemo() {
    return (
      <Button className="glass">
        Haz clic aquí
      </Button>
    )
  }`
  } />

## Examples

Glass UI buttons are designed to be composable. By default, they have a transparent background, and you can apply different utility classes to achieve the desired glassmorphism effect.

### Default

A basic button without glass classes. It features a transparent background and subtle hover states.

<ComponentPreview name="button-default" client:visible />

### Glass

Applies the standard glassmorphism effect, combining backdrop blur, subtle borders, and a translucent background.

<ComponentPreview name="button-glass" client:visible />

### Glass Soft

A softer, more transparent glass effect. Ideal for secondary actions that shouldn't compete with the primary UI elements.

<ComponentPreview name="button-glass-soft" client:visible />

### Glass Strong

A pronounced glass effect with higher opacity, perfect for high-emphasis actions or elements resting over complex backgrounds.

<ComponentPreview name="button-glass-strong" client:visible />

### Disabled

Displays a disabled state with reduced opacity and disabled pointer events.

<ComponentPreview name="button-disabled" client:visible />

### Combinations

You can place multiple button variants together to establish a clear visual hierarchy in your interfaces.
