## Styling

Slider follows the same prop-first pattern as the other form controls. Reach for `variant` and `size` first, then use `className` as an escape hatch.

<CodeBlock
  lang="tsx"
  code={`<Slider defaultValue={[24]} aria-label="Volume" />
  <Slider variant="soft" defaultValue={[32]} aria-label="Brightness" />
  <Slider variant="strong" size="lg" defaultValue={[48]} aria-label="Contrast" />
  <Slider variant="transparent" className="max-w-xs" defaultValue={[12]} aria-label="Blur" />

  /* Controlled */
  <Slider value={[value]} onValueChange={(nextValue) => setValue(nextValue[0])} aria-label="Opacity" />`}
/>

## API Reference

Accepts all Radix `Slider.Root` props.

| Prop | Type |
| --- | --- |
| `variant` | `"default" \| "soft" \| "strong" \| "transparent"` |
| `size` | `"sm" \| "md" \| "lg"` |
| `value` | `number[]` |
| `defaultValue` | `number[]` |
| `onValueChange` | `(value: number[]) => void` |
| `min` | `number` |
| `max` | `number` |
| `step` | `number` |
| `disabled` | `boolean` |
| `className` | `string` |
